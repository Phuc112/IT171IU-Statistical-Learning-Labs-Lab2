## Lab Overview
This laboratory covers simple and multiple linear regression using `statsmodels` and the `ISLP` library. Topics include:
* Model estimation, inference, $t$-statistics, $p$-values, and $R^2$ evaluation.
* Confidence intervals for mean response versus prediction intervals for individual observations.
* Diagnostic checks (residual plots, studentized residuals, leverage, and variance inflation factors for collinearity).
* Advanced extensions: interaction terms, polynomial transformations, qualitative predictors, and nested model comparisons using `anova_lm()`.
